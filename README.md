# E-Commerce Sales & Customer Analytics

## Project Overview

This portfolio project analyzes an e-commerce dataset using Excel, SQL, Power BI, and Looker Studio. It presents the workflow from data preparation and analysis through dashboard development and business reporting.

## Tools Used

- **SQL:** Data analysis and querying
- **Excel:** Data preparation, cleaning, and source data management
- **Power BI:** Interactive dashboard development and reporting
- **Looker Studio:** Dashboard visualization and presentation

## Project Workflow

1. Prepared and cleaned the source data in Excel.
2. Performed SQL-based analysis and documented the SQL work.
3. Built an interactive Power BI report for sales and customer analysis.
4. Created Looker Studio dashboard views for additional visualization.
5. Documented the SQL work, Power BI analysis, and supporting screenshots in the project documentation.
